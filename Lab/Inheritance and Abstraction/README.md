1. Objective

To develop a simple banking system using Python that demonstrates abstraction, inheritance, and type hints.

2. Input
   
Withdrawal amount: 500

Initial balance is not required because this short example only demonstrates the withdrawal method.

4. Output
   
Withdrawn: 500

6. Algorithm

1.Start.

2.Create an abstract class Bank with an abstract withdraw() method.

3.Create the Savings class that inherits from Bank.

4.Implement the withdraw() method in the Savings class.

5.Create a savings account object.

6.Call the withdraw() method with amount 500.

7.Display the withdrawal amount.

8.Stop.

7. Time Complexity

O(1) — The withdrawal method performs a constant-time print operation.

8. Space Complexity

O(1) — The program uses a constant amount of extra memory.
